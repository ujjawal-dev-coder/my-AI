# 🎙️ QODEOVA - Virtual Voice Assistant

**QODEOVA** is a sleek, web-based voice assistant that uses the Web Speech API to perform tasks through voice commands. Featuring a futuristic "Orb" UI and a glassmorphism design, it provides a seamless interaction experience.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-brightgreen.svg)

---

## ✨ Features

- 🗣️ **Voice Recognition:** Powered by `WebSpeechAPI` for high accuracy.
- 🔊 **Text-to-Speech:** Responds to you with a professional AI voice.
- 🌐 **Web Automation:** Open YouTube, Google, ChatGPT, and more via voice.
- 📱 **Mobile Integration:** Can trigger mobile apps like WhatsApp, Instagram, and Spotify.
- 🔍 **Smart Search:** If it doesn't recognize a command, it automatically searches Google for you.
- 🎨 **Futuristic UI:** Pulse-animated orb and glassmorphism container.
